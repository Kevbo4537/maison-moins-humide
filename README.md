# Maison Moins Humide

Site Astro statique SEO/affiliation sur l’humidité dans le logement.

## Objectif

Aider les particuliers à comprendre, mesurer et réduire l’humidité dans une maison ou un appartement, avec un ton simple, rassurant et prudent.

## Commandes

```bash
npm install
npm run dev
npm run build
npm run preview
npm run check:seo
```

## Structure

- `src/pages/` : pages statiques Astro
- `src/components/` : composants UI
- `src/layouts/` : layouts de base, article et comparatif
- `src/styles/global.css` : styles globaux
- `public/robots.txt` : robots
- `astro.config.mjs` : configuration Astro + sitemap

## Pages V1

- Accueil
- 6 guides humidité
- 5 pages par pièce
- 4 comparatifs
- Produits utiles
- Pages légales/confiance
