# Maison Moins Humide — liste d’actions Kevin

Objectif : garder une liste courte, imprimable, des choses que Kevin doit faire quand l’agent ne peut pas agir seul.

## Règle simple

Si l’agent peut faire seul : il fait.
Si l’agent ne peut pas faire seul : il demande à Kevin une action courte, avec la raison et le délai conseillé.

## Actions que Kevin devra parfois faire

### 1. Fournir les chiffres Amazon Partenaires

Quand : une fois par mois, ou quand l’agent le demande.

À fournir :
- nombre de clics ;
- nombre de commandes ;
- gains ;
- produits commandés si visible ;
- période concernée.

Pourquoi : savoir quelles pages et quels produits rapportent vraiment.

Instruction courte : faire une capture ou copier les chiffres principaux du tableau Amazon Partenaires.

### 2. Fournir les données Google Search Console

Quand : après quelques semaines de présence Google, puis une fois par mois.

À fournir :
- requêtes qui affichent le site ;
- pages qui reçoivent des impressions ;
- clics ;
- position moyenne si disponible.

Pourquoi : renforcer les pages qui commencent déjà à monter au lieu d’écrire au hasard.

Instruction courte : envoyer une capture des performances Search Console sur les 28 derniers jours.

### 3. Créer ou envoyer des liens affiliés Amazon France

Quand : quand l’agent repère un produit utile mais n’a pas le lien affilié.

À fournir :
- lien court Amazon Partenaires exact ;
- nom du produit si possible ;
- image produit si Amazon ne permet pas de l’utiliser proprement.

Pourquoi : ajouter des blocs produits qui peuvent générer une commission.

Instruction courte : créer le lien dans Amazon Partenaires et l’envoyer sans le modifier.

### 4. Valider certains produits

Quand : si le produit touche à l’électricité, ventilation, moisissures fortes ou traitement bâtiment.

À valider :
- le produit est cohérent avec le problème ;
- il ne promet pas de miracle ;
- il est disponible sur Amazon France ;
- il ne semble pas dangereux ou douteux.

Pourquoi : garder un site crédible et éviter les mauvais conseils.

Instruction courte : dire “ok”, “non”, ou “remplacer par …”.

### 5. Donner une décision éditoriale si nécessaire

Quand : si plusieurs directions sont possibles.

Exemples :
- créer une page très achat ;
- créer une page plus conseil ;
- accepter ou refuser une catégorie de produits ;
- prioriser salle de bain, cave, chambre ou comparatifs.

Pourquoi : ne pas perdre du temps sur une direction qui ne t’intéresse pas.

Instruction courte : choisir une option parmi celles proposées.

## Format que l’agent doit envoyer à Kevin

Quand une action est nécessaire, le message doit tenir en quelques lignes :

- **À faire :** action précise.
- **Pourquoi :** impact attendu.
- **Délai conseillé :** maintenant / cette semaine / ce mois-ci.
- **À m’envoyer :** lien, capture ou réponse attendue.

## Priorité des demandes

1. Données Google Search Console.
2. Données Amazon Partenaires.
3. Liens affiliés Amazon France.
4. Validation de produits.
5. Choix éditoriaux.

## Ce qu’il ne faut pas demander à Kevin inutilement

- relire chaque petite modification ;
- choisir chaque titre ;
- valider chaque lien interne ;
- faire des recherches que l’agent peut faire seul ;
- fournir des données trop détaillées si une simple capture suffit.
